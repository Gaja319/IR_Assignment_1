# IR Assignment 1 — End-to-End

Run the pipeline and Streamlit demo for the Information Retrieval assignment.

Requirements

- Python 3.8+
- Install dependencies:

```bash
python -m pip install -r requirements.txt --break-system-packages
```

Run the pipeline:

```bash
python run_pipeline.py
```

Run the Streamlit demo:

```bash
streamlit run app.py
```

Outputs are written to the `outputs/` folder by `run_pipeline.py`.
